# Security

If you find a security problem in this code, in the programs it deploys, or in Rome's devnet deployment of them,
please email rome@romeprotocol.com rather than opening a public issue. Tell us what you found, how to
reproduce it, and which version or commit you used. Please give us a reasonable time to fix it before you share
it publicly.

The devnet deployment is for testing and holds no real value. [`docs/TRUST-MODEL.md`](docs/TRUST-MODEL.md) says
what each part of the system trusts and what an operator or Rome can still change.
